# Raw Data

Raw downloaded source files belong under the source-specific folders in this directory.

Rules:

- Do not edit files under `data/raw/`.
- Record each file in `data/source_registry.csv`.
- Preserve source filenames where practical.
- Hash raw files when implementing automatic downloads.

PLFS 2024 public-use files were downloaded under `data/raw/plfs`. NFHS/NSS files that require registration or approval must still be obtained through their official access workflows.
